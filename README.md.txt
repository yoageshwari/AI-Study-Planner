
# 🤖 AI Study Planner Agent

## 📌 Project Description

AI Study Planner Agent is a simple Agentic AI application that creates personalized study schedules for students.

The user provides their subjects, exam duration, available study hours, and difficult subjects. The AI agent analyzes these inputs and generates a realistic study plan.

## 🎯 Objective

The objective of this project is to demonstrate a basic application of Agentic AI using an AI model.

## ⚙️ How It Works

1. The student enters their study information.
2. The application sends the information to the AI agent.
3. The agent analyzes the student's requirements.
4. The AI model creates a personalized study schedule.
5. The generated plan is displayed to the student.

## 🧠 Agentic AI Concept

The project demonstrates a simple goal-oriented AI agent.

The goal of the agent is:

> Create a personalized study plan.

The agent considers different constraints such as:

- Number of subjects
- Number of days
- Available study hours
- Difficult subjects

It then generates a suitable plan.
